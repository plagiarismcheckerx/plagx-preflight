# Observable notebook

The cells of the [Plagx Preflight Observable notebook](https://observablehq.com/@plagiarismcheckerx/plagx-preflight), in order. Paste each one into a new cell on observablehq.com.

The notebook loads the published [plagx-preflight npm package](https://www.npmjs.com/package/plagx-preflight) from jsDelivr. To update it, change the version number in cell 2.
